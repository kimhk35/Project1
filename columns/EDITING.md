# AI Insight Column 편집 원칙

지금까지 발행한 칼럼(본연재 제3·4회 Spin-Off 1·2)에서 지켜 온 원칙을 정리하고 새 원칙 하나를 더한다
새 원고는 이 원칙을 따르고 `columns/build_docx.py`로 DOCX를 만든다

## 1 문체

- 합니다체 1인칭 ‘저’ 수학 교사이자 연구자의 목소리로 쓴다
- 이론보다 교실 장면이나 독자의 질문에서 출발한다
- 확신이 없는 곳은 확신이 없다고 쓴다 주장의 범위를 먼저 좁혀 두고 그 안에서 말한다

## 2 문장부호

- 쌍따옴표를 쓰지 않는다 인용과 강조는 ‘ ’
- 칼럼 제목은 「 」 연재 이름은 〈 〉 책 제목은 『 』
- 본문 문장은 온점으로 끝낸다 제목 소제목 표 안의 짧은 항목에는 온점을 찍지 않는다

## 3 개념을 빌려 올 때

- 새로 붙인 이름은 잠정적 표현임을 첫머리 ※ 안내에 밝힌다
- 빌려 온 개념은 어디까지 빌리는지 밝힌다 (제4회 방어선)
- ‘AI가 이러하니 사람도 이래야 한다’ 형태의 문장을 쓰지 않는다
- 에이전트 쪽 용어를 그대로 교실에 들이지 않는다

## 4 근거와 인용

- 실제로 있는 문헌만 인용한다 확인하지 못한 수치나 연구는 쓰지 않는다
- 본문은 저자(연도) 형식 끝에 APA 형식 참고 문헌 목록
- 지난 회차를 가리킬 때는 회차와 제목을 함께 쓴다

## 5 독자 댓글을 다룰 때

- 댓글 작성자는 닉네임에 ‘님’을 붙여 부른다
- 원문을 그대로 옮기기보다 취지를 요약하고 요약했다는 사실을 ※ 안내에 밝힌다
- 칼럼 논지와 무관한 사담(책 출간 이야기 농담 개인 신상)은 싣지 않는다
- 도움을 준 독자에게는 글 끝에 감사를 전한다

## 6 구성

1. 제목 + 머리 줄(시리즈 표기 — 부제) + ※ 안내
2. 출발 장면
3. 소제목으로 나눈 본문 (질문형 또는 선언형 소제목)
4. 한 문장으로 정리하면 (핵심 문장 한 단락)
5. 생각해볼 문제 두 개 (독자가 자기 교과와 교실에 대입할 수 있는 질문)
6. 참고 문헌

## 7 서식

| 요소 | 서식 |
|---|---|
| 용지 | A4 여백 25mm |
| 글꼴 | 맑은 고딕 |
| 제목 | 15.5pt 굵게 남색 #1F3864 |
| 머리 줄 | 10pt 회색 #595959 |
| ※ 안내 | 9.5pt 회색 |
| 소제목 | 12pt 굵게 남색 |
| 본문 | 11pt 검정 줄 간격 1.5 |
| 핵심 문장 | 10.5pt 굵게 남색 좌우 8mm 들여쓰기 |
| 표 | 9.5pt 머리 행 옅은 남색 바탕 |
| 생각해볼 문제 | 본문 크기 번호만 굵게 |
| 참고 문헌 | 9pt 7mm 내어쓰기 |

## 8 정렬 (새 원칙)

- 제목과 소제목을 뺀 모든 문단은 양쪽 정렬한다 왼쪽 정렬을 쓰지 않는다
- 본문 머리 줄 ※ 안내 핵심 문장 생각해볼 문제 참고 문헌 표 안의 설명 칸 모두 해당
- 표의 머리 행과 번호 칸만 가운데 정렬
- `build_docx.py`가 기본으로 양쪽 정렬을 적용하므로 Word에서 다시 손볼 때도 정렬을 바꾸지 않는다
