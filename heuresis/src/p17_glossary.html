용어 사전/GLOSSARY

이번 호를 읽는 54개의 말

연구 방법과 교육 AI의 용어를 가나다와 알파벳 순으로 모았다 정의는 이 잡지의 맥락에 맞춘 짧은 설명이다

Delphi

전문가 패널이 여러 차례 익명 설문으로 합의를 모아 가는 방법

E2E 구조 end-to-end

하나의 모델이 입력에서 최종 출력까지 한 번에 처리하는 구조

ICC intraclass correlation

여러 채점자나 반복 측정의 일치 정도 절대합치 ICC(A,1)는 점수 수준까지 같아야 높다

IPA importance-performance analysis

항목별 중요도와 수행도를 함께 그려 개선 우선순위를 찾는 분석

PRISMA

체계적 고찰의 검색 선정 보고 절차를 표준화한 지침

RAG retrieval-augmented generation

검증된 자료를 검색해 LLM의 답변 생성에 붙이는 방식 정확성을 높이지만 교육 효과를 보장하지 않는다

pipeline 구조 pipeline

규칙 검색 모델 교사 검토 등 여러 단계를 나누어 연결한 구조 각 단계를 점검할 수 있다

가르칠 수 있는 에이전트 teachable agent

학생이 AI에게 개념을 가르치며 배우도록 설계한 에이전트 가르치는 과정의 설명 행동이 학습을 이끈다

가중 카파 weighted κ

순서가 있는 점수에서 두 채점자의 일치를 우연 일치를 빼고 계산하되 가까운 불일치에 부분 점수를 주는 지표

거버넌스 성숙도 governance maturity

사용 전략 연수 학생 참여 모니터링 책임의 여섯 계단이 문서와 실제로 갖춰진 정도

검정력 statistical power

실제로 효과가 있을 때 그것을 통계적으로 찾아낼 확률 표본이 작으면 낮아진다

과정 마이닝 process mining

행동 로그에서 활동의 순서와 흐름을 모형으로 찾아내는 분석

과정 증거 process evidence

최종 답안 외에 중간 표현 수정 이유 로그 구두 설명처럼 학습 과정을 보여 주는 자료

교차지연 패널 cross-lagged panel

여러 시점의 두 변수가 서로를 얼마나 앞서 예측하는지 보는 종단 분석

군집 무작위 시험 cluster RCT

학생 개인이 아니라 학급이나 학교 단위로 조건을 무작위 배정하는 실험

근거 사다리 evidence ladder

PRAXIS가 쓰는 인과 주장 강도의 다섯 칸 표기 개념 논평에서 무작위 시험 메타분석까지

다층모형 multilevel model

학생이 학급에 학급이 학교에 속하는 위계 구조를 반영하는 회귀 모형

데이터 시민성 data citizenship

데이터가 모이고 쓰이는 관행을 이해하고 통계적 주장을 평가하며 행동을 성찰하는 역량

리빙 메타분석 living meta-analysis

새 연구가 나올 때마다 갱신되는 메타분석

멀티모달 학습분석 multimodal learning analytics

로그 음성 영상 생리 신호 등 여러 종류의 자료를 함께 분석해 학습을 이해하는 방법

메타분석 meta-analysis

여러 연구의 효과크기를 통계적으로 합쳐 전체 경향과 이질성을 추정하는 방법

무작위 시험 RCT

참여자를 조건에 무작위로 배정해 조건 외의 차이를 확률적으로 고르게 만드는 실험

베이즈 요인 Bayes factor BF10

한 가설이 다른 가설보다 자료를 몇 배 더 잘 설명하는지 나타내는 값 100이 넘으면 매우 강한 증거로 본다

사전등록 preregistration

자료 수집 전에 가설과 분석 계획을 공개 기록해 두는 절차

생성형 UI generative UI

자연어 설명으로 조작 가능한 화면과 활동을 생성하는 인터페이스

서지계량 bibliometrics

논문 수 인용 공저 관계로 연구 분야의 지형을 분석하는 방법

성장마인드셋 growth mindset

능력이 노력과 전략으로 자랄 수 있다는 믿음

숙달 진행 mastery progression

일정 기준을 넘어야 다음 단계로 넘어가게 하는 학습 규칙

시선 추적 eye tracking

실행 충실도 implementation fidelity

개입이 설계대로 실제로 실행된 정도 무효과의 원인을 가를 때 중요하다

에이전트형 AI agentic AI

질의응답을 넘어 계획하고 도구를 써서 업무를 실행하는 AI

오개념 misconception

일관된 논리를 가진 잘못된 개념 단순 실수와 달리 반복된다

요인 설계 factorial design

두 개 이상의 처치를 교차해 주효과와 상호작용을 함께 보는 실험 설계 2×2 등

인식론적 주도권 epistemic agency

무엇을 참으로 받아들일지 스스로 판단하고 정당화하는 학생의 권한과 역량

인지적 오프로딩 cognitive offloading

생각의 일부를 도구에 맡기는 것 과하면 독립 수행이 약해질 수 있다

일반화가능도 이론 G theory

채점자 문항 상황 등 여러 오차 원천을 한꺼번에 분해해 점수의 신뢰도를 추정하는 이론

잠재전이 분석 LTA

전이 transfer

무작위 배정 없이 비교 집단을 두어 효과를 추정하는 설계

증거 타당도 validity of evidence

차별 문항 기능 DIF

체계적 고찰 systematic review

명시된 검색과 선정 기준으로 관련 연구를 빠짐없이 모아 종합하는 방법

측정동일성 measurement invariance

판단노동 judgment labor
